# Excel Automation Project

## Project Overview

This project automates employee salary processing using Python and Pandas.

It reads employee data from an Excel file, calculates bonuses, assigns employee status based on salary, generates a summary report, and saves everything into a new Excel workbook.

---

## Features

- Read employee data from an Excel file
- Calculate a 10% bonus for each employee
- Assign employee status:
  - High Salary (Salary > 50000)
  - Standard (Salary <= 50000)
- Generate summary statistics
- Export results to a new Excel workbook

---
